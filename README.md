# Lit Portfolio Demo App

A modern, fast, and lightweight portfolio web application built with Web Components using [Lit](https://lit.dev/).

## 🚀 Live Demo

Check out the live deployment here: [https://lit-dev-green.vercel.app/](https://lit-dev-green.vercel.app/)

## 🛠️ Tech Stack

- **Framework**: [Lit](https://lit.dev/) (Web Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Running Locally

To get this project up and running on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/viralpatel16890/lit-dev.git
   cd lit-dev
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173/`.

## 📦 Build for Production

To build the application for production, run:
```bash
npm run build
```
This will generate the compiled files in the `dist/` directory, ready to be deployed.
